# Эскизно — прототип редактора v0.4

Самостоятельный интерфейсный прототип первого урока «Ветка с листьями».
Это **не** основной продукт и не замена утверждённому React + Canvas2D MVP.
Здесь проверяется рабочее место рисования без декоративных блоков: приоритет
холста, компактные инструменты и короткие инструкции справа или под холстом.

## Запуск

Из каталога `prototypes/stylus-editor-v1`:

```bash
python3 -m http.server 8000
```

Открыть `http://localhost:8000` в браузере. Установка пакетов не нужна.
Для планшета и телефона открыть тот же адрес через доступный локальный сервер.

## Что работает

- Canvas2D: рисование стилусом, мышью и пальцем, кисть и три цвета.
- Масштаб холста от 100% до 400%: кнопки `− / +`, возврат на 100%,
  колесо мыши над холстом или жест двумя пальцами. Двумя пальцами можно
  также перемещать увеличенный рисунок. Панель инструментов и инструкция
  при этом не масштабируются. PNG экспортируется целиком при 100%.
- Ластик стирает **только участок под движением** (как кисть) и имеет
  отдельную толщину 4–50 px. Стирание — отдельное отменяемое действие.
  Учебные направляющие не затрагиваются.
- Толщина кисти и ластика регулируется отдельно: в боковой панели на
  компьютере/планшете или ползунком «Размер» под холстом на телефоне.
  При переключении инструментов каждое значение сохраняется. В шапке
  показана версия **v0.4** — если её нет, открыт устаревший набор файлов.
- Отмена/повтор, 6 шагов одного урока, режимы «Повтори / Пойми / Сам».
- Переключение подсказок для взрослых и детей.
- Автосохранение в `localStorage` конкретного браузера и выгрузка PNG без
  вспомогательных направляющих. Экспорт включает штрихи текущего и предыдущих
  шагов, но не будущих.
- Адаптивное расположение инструментов и урока для узкого экрана.
- Планшетная панель урока: две явные колонки с отдельными позициями
  элементов, чтобы шаги и кнопки не уходили за нижнюю границу.

## Проверка

```bash
node --test core.test.mjs ink.test.mjs ui.test.mjs
node --check app.mjs
```

Пиксельные проверки из `ink.test.mjs` используют необязательный пакет
`@napi-rs/canvas`, когда он доступен. Без него эти два теста пропускаются;
это не заменяет браузерные проверки.

`browser.test.mjs` — отдельные интеграционные тесты для Playwright и Chromium:
они ожидают запущенный сервер на порту `8765`, установленный Playwright и
доступный исполняемый Chromium `/usr/bin/chromium`. Автоматическая проверка
визуального отображения и реального пера на физических устройствах **не
подтверждена**; она остаётся обязательной перед переносом дизайна в MVP.

Если после обновления ластик всё ещё удаляет целые линии, скачайте заново
**всю папку прототипа** из ветки `prototype/plain-editor` (включая новый
`ink.mjs`), перезапустите локальный сервер и принудительно обновите страницу.
Это важно: zip ветки `main` не содержит изменений чернового PR #4.

## Границы прототипа

- Только один демонстрационный урок; здесь нет аккаунтов, каталога и оплаты.
- История Undo/Redo не переживает перезагрузку, сохраняются сами штрихи.
- Автосохранение зависит от локального хранилища браузера.
- Подсказки нарисованы оригинальными простыми векторными линиями программно,
  без растровых изображений или генеративной графики.
