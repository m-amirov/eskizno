# E1 — ручная приёмка на устройствах и реальных рисунках

**Статус:** ожидает испытания на физических устройствах. Это не сертификат готовности продукта и не разрешение на merge или публикацию.

## Подготовка

1. Открыть именно ветку `feat/e1-7-finish` (Draft PR #14 включает предыдущие E1-ветки), не запускать старую сборку из `main`.
2. На компьютере: `cd apps/web && npm ci && npm run lan`.
3. На компьютере открыть `http://localhost:5173/`. На устройстве в той же локальной сети открыть `http://<IP-компьютера>:5173/`; IP в Windows можно узнать через `ipconfig`.
4. Подготовить **свои** 2–3 файла PNG/JPEG/WebP: простой контур для обводки, фотографию/скан для бокового референса и ещё один заметно отличающийся рисунок. Не публиковать их для проверки: импорт должен оставаться локальным.
5. Перед проверкой записать модель устройства, версию ОС, браузер и его версию, способ ввода (палец/мышь/модель стилуса), ориентацию экрана. Если стилуса нет, отметить **NOT TESTED**.

## Матрица проверки

| Платформа | Что фактически проверено автоматически | Что остаётся проверить вручную |
| --- | --- | --- |
| Desktop, Chromium, 1280×800 | 27 E2E, снимок интерфейса; без горизонтального overflow | Удобство рисования мышью с реальным рисунком |
| Tablet, Chromium viewport 768×900 | Снимок и измерение холста при открытых слоях | Реальный планшет, касание, масштабирование двумя пальцами, ориентация |
| Phone, Chromium viewport 390×844 | Снимок и измерение холста при открытых слоях | Реальный телефон, доступность инструментов через прокрутку, касание |
| Физический стилус | **NOT TESTED** | Непрерывный штрих, отмена жеста, блокировка прокрутки при рисовании, контакт ладони |

Синтетические снимки и браузерные тесты: [E1 browser gate #28](https://github.com/m-amirov/eskizno/actions/runs/42761790107). Они не заменяют испытания физических устройств.

## Сценарии для каждого доступного устройства

Отметить `PASS`, `FAIL` или `NOT TESTED` у каждого сценария, приложить скриншот или короткую запись **только если это безопасно для личных изображений**.

- [ ] **Чистый холст:** создать новый рисунок; нарисовать длинный штрих и короткие штрихи; сменить кисть и размер, использовать ластик, Undo и Redo. Проверить, что штрих идёт под указателем/пером и не исчезает при отпускании.
- [ ] **Два касания:** начать штрих пальцем, коснуться вторым пальцем, выполнить pan/pinch; проверить, что незавершённый штрих не добавился. Отдельно проверить `pointercancel`, если устройство позволяет воспроизвести отмену.
- [ ] **Панели:** раскрыть слои, переименовать слой, изменить прозрачность, скрыть/показать и заблокировать; область рисования остаётся достаточно большой, элементы панели доступны через вертикальную прокрутку, нет горизонтальной прокрутки.
- [ ] **Обводка:** импортировать первый личный файл поверх холста; рисовать на независимом paint-слое; ластик и Undo не стирают референс; скрыть референс, перезагрузить страницу и восстановить работу.
- [ ] **Референс рядом:** создать второй проект с другим изображением. На компьютере проверить увеличенную панель, изменение ширины мышью и клавишами ←/→; на планшете и телефоне — положение панели над холстом, сворачивание и доступность холста при прокрутке. Проверить fullscreen и восстановление референса после перезагрузки.
- [ ] **Просмотр референса:** проверить ±, ползунок 25–400%, колесо, pinch двумя пальцами и перетаскивание увеличенного изображения; «Вписать» возвращает исходный вид. Убедиться, что при заблокированном слое зум просмотра доступен, а масштаб рисунка, штрихи, PNG и положение самого слоя не меняются. При открытии другого проекта увеличение должно сбрасываться.
- [ ] **Галерея:** создать третий проект с отличающимся изображением; открыть проекты из «Мои работы», проверить превью и сохранённые слои; удалить один проект только после подтверждения и убедиться, что остальные не затронуты.
- [ ] **Экспорт:** скачать PNG с включённым и выключенным наложенным референсом; проверить корректность размера, изображения и прозрачности в независимом просмотрщике.
- [ ] **Ошибки:** неподдерживаемый или битый файл не заменяет текущую работу; при ошибке сохранения интерфейс не показывает ложное «Сохранено». Имитировать отказ IndexedDB безопаснее в изолированном браузерном профиле, чтобы не рисковать существующими работами.
- [ ] **Приватность:** убедиться, что импорт работает локально и не требует передачи личного файла на сервер; сетевые запросы проверять в инструментах разработчика браузера, если доступны.
