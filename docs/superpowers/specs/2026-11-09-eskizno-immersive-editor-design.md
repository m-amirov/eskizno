# Эскизно — палитра, жесты и полноэкранная студия

Утверждено пользователем 09.11.2026: вариант А — полноэкранная студия с компактными инструментами; все изменения идут в Draft PR #10 без merge.

## Назначение и границы

Взрослый учащийся рисует мышью, пальцем или стилусом. Инструменты не должны мешать рисунку, а увеличение — приводить к случайным штрихам или прокрутке страницы. Не меняем сериализуемую модель проекта, не добавляем сервер, внешние UI-библиотеки, сохранение после перезагрузки или инструменты этапа E1.4.

## Подходы и решение

- **А (выбран):** полноэкранный DOM-контейнер редактора со своим компактным toolbar, холстом и слоями. `requestFullscreen()` по явному нажатию, `fullscreenchange`/Esc синхронизируют состояние; при отсутствии API — локальный CSS-режим фокусировки с честным пояснением, что браузерная рамка остаётся.
- **Б (отклонён):** чистый холст со скрытыми инструментами. Даёт больше места, но делает смену кистей/цветов менее удобной на планшете.
- **PWA standalone (не входит):** другой процесс установки и поддержания приложения, не нужен для MVP.

## Внешний вид

Основа текущей визуальной системы: лесной зелёный `#315C46`, бумага `#FFFDFA`, фон рабочей области `#F0F2EE`, графит текста `#24352F`, вспомогательный серо-зелёный `#718077`, тёплый акцент `#C18B42`. Один текущий системный гротеск и компактная типографика инструментов; главный визуальный акцент — рисунок, не декоративные панели. Палитра — всплывающая карточка под цветовой кнопкой, с крупными цветовыми кругами и пользовательским цветом, не занимает место в toolbar, закрывается по Esc/клику снаружи.

## Поведение и критерии

1. Кнопка «Палитра» показывает выбранный цвет; всплывающая панель содержит цвета проекта, выбор HEX через native color input, добавление произвольного цвета в палитру (без дубликатов, максимум 32). Смена цвета не меняет размер холста и применима к следующим штрихам. Закрытие — Esc, клик вне, выбор образца. У ластика цвет не меняет результат.
2. Колёсико мыши над холстом масштабирует 1…4 с привязкой к курсору, не прокручивая страницу; native `wheel` listener `{passive:false}`. Прокрутка вне холста остаётся обычной. `deltaMode` (pixels/lines/pages) нормализуется; непредвиденные/нечисловые значения игнорируются. Пиксельный размер canvas не меняется.
3. Первое касание рисует, два касания — `pinchView` с масштабом вокруг середины и pan. Второе касание отменяет, а не завершает незаконченный штрих; после отпускания одного пальца штрих не возобновляется до нового касания. Pen/mouse однопальцевым жестом не ломаются. `pointercancel` не коммитит.
4. Кнопка «Полный экран» помещает только `studio-layout` в top-layer. Toolbar, холст, слои и кнопка выхода остаются; шапка/описания сайта не участвуют. Доступный холст вписывается без искажения соотношения сторон 4:3; `getBoundingClientRect` остаётся реальной зоной рисования. `fullscreenchange` после Esc возвращает обычный layout. Если API недоступен/отказывает — CSS-режим фокуса, закрываемый кнопкой и Esc; пользователь видит короткое пояснение.
5. Адаптивность на телефоне; zoom/focus не стирают историю. Проверки: unit поведение и геометрия, Playwright pointer/wheel/fullscreen на поддерживаемом браузере. Нельзя обозначать браузерную приёмку PASS, если Chromium не стартует.
