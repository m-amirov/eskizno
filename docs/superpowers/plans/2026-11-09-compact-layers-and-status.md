# Visual Audit — Step 4: Layers and Editor Status

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Упростить визуальную иерархию боковой панели слоёв и строки состояния, убрать избыточные подписи и стилистически несогласованные глифы, сохраняя поведение редактора.

**Architecture:** Не менять модель/историю/жесты слоёв. В `LayerList` оставлять маркер выбранного слоя в `aria-label` и состоянии строки, но не в видимом названии; заменить символьные `⋯`/`⠿` на пиктограммы из существующего `ToolIcon`. В `EditorCanvas` свернуть заголовок мобильной панели до «Слои (N)» с шевроном, сократить вводный текст и предупреждение об отсутствии сохранения. Подсказку об удержании показывать контекстно, когда она уместна.

**Tech Stack:** React 19, TypeScript, CSS, Vitest, Playwright.

**Spec:** Утверждённый визуальный аудит, шаг 4. Предыдущие шаги: `2026-11-09-fit-studio-artboard.md`, `2026-11-09-compact-color-palette.md`, `2026-11-09-responsive-studio-toolbar.md`.

## Constraints

- Текущая зелёная палитра, шрифтовое семейство, все функции слоёв, Undo/Redo, лимиты и безопасность удаления сохраняются.
- Предупреждение должно честно говорить, что после перезагрузки рисунок пропадёт; не обещать сохранение, пока его нет.
- Доступность: `aria-pressed`, имена кнопок, клавиатурная перестановка и видимый фокус работают как раньше.
