# Шаг 5 визуального аудита — «Мои работы»

## Цель

Заменить широкую пустую карточку на лаконичное состояние личной галереи: рисунок, а не UI-обёртка, должен быть центром визуального языка. Не создавать впечатление, будто сохранение уже работает.

## Решение

- Убрать повторяющийся кикер «Ваше пространство» и обширный bordered-card.
- Построить компактную редакционную композицию: миниатюра **пустого листа** из CSS и содержательный текст с одним явным действием «Перейти в студию».
- Фактически сообщить, что сохранение ещё не доступно, а черновик теряется при перезагрузке.
- На узком экране выстроить изображение, пояснение и кнопку в одну колонку без горизонтальной прокрутки.
- Использовать исключительно существующие цвета, семейство шрифта и стили кнопок. Не добавлять декоративные градиенты или сторонние изображения.

## Реализация и проверки

1. Написать unit-тест на пустое состояние, честное сообщение и возврат в студию; выполнить RED.
2. Обновить только `apps/web/src/App.tsx` и стили `projects-page` в `apps/web/src/styles.css`.
3. Добавить мобильный Playwright-сценарий в `apps/web/e2e/app.spec.ts` и проверить доступность названия/действия и отсутствие горизонтального переполнения.
4. Выполнить unit, build, `git diff --check` и доступную браузерную проверку. Не считать browser gate пройденным, если Chromium не запускается.
5. Отправить отдельный коммит в Draft PR #10, обновить описание, не переводить PR в Ready и не сливать в `main`.
