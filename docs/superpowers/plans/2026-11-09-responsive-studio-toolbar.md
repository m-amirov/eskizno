# Visual Audit — Step 3: Responsive Studio Toolbar

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Убрать случайные переносы и тесноту панели инструментов при 390px, 820px, 1305px и при выборе фигур, без горизонтальной прокрутки страницы или скрытых действий.

**Architecture:** В `EditorCanvas` сгруппировать элементы панели по назначению, сохранив существующие кнопки, подписи, aria-label и состояния. CSS на широком экране допускает одну строку, при выборе фигур приоритетно переносит настройки кисти целой группой; на планшете и телефоне выделяет стабильные строки для инструментов, действий, списков фигур и двух ползунков. Никаких новых меню и зависимостей.

**Tech Stack:** React 19, TypeScript, CSS, Vitest, Playwright.

**Spec:** Утверждённый план визуального аудита Эскизно от 09.11.2026, шаг 3 — адаптивная панель инструментов. Предыдущие этапы: `2026-11-09-fit-studio-artboard.md`, `2026-11-09-compact-color-palette.md`.

## Constraints

- Цвета, шрифты, SVG-иконки, выбор кисти, ведро, инструменты фигур, удержание 500 мс, Undo/Redo, fullscreen, ползунки и документ не меняются функционально.
- Минимум два читаемых ползунка на планшете/телефоне, нажатие мышью/пальцем, доступ с клавиатуры.
- Цель для телефонов — панель не выходит за ширину viewport, все действия видимы, а холст остаётся главным рабочим элементом.
