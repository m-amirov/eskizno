# Эскизно / Eskizno

Эскизно — браузерное обучение цифровому рисованию для взрослых. Основной сценарий — рисовать на холсте в браузере, прежде всего стилусом на планшете, с поддержкой мыши и касаний. Учебные навыки должны переноситься в другие графические редакторы.

**Статус:** идёт поэтапная разработка. Самостоятельный прототип редактора v0.4 находится в `prototypes/stylus-editor-v1`. В `apps/web` работает холст Canvas2D со слоями, историей, цветовой палитрой и десятью кистями (карандаш, линер, маркер, мягкая кисть, акварель, уголь, сухая кисть, аэрограф, каллиграфия, пастель). Слои можно переименовывать через меню `⋯`; завершённые штрихи кэшируются для отзывчивого рисования. Добавлены ведро, заливка фигур, прозрачность кисти и редактируемые геометрические фигуры с перемещением/маркерами размера. E1.5 добавляет локальное автосохранение в IndexedDB и галерею «Мои работы»; E1.6 — три режима студии и импорт своего эскиза. Для E1.5–E1.6 пройдены 23/23 E2E в Chromium [GitHub Actions #12](https://github.com/m-amirov/eskizno/actions/runs/42758320225); обе стадии пока в Draft PR. E1.7 расширяет палитру и экспорт. Уроки и интерактивная оценка рисунков ещё не реализованы.

### Локальные работы (E1.5)

- Изменения в рисунке сохраняются автоматически с короткой задержкой. В боковой панели показывается фактический статус записи. При ошибке доступны повторная попытка и скачивание PNG с текущего холста.
- В «Моих работах» можно создать новую работу, открыть сохранённую или удалить её после подтверждения. Превью рисуется по содержимому самого проекта.
- Проекты и вложения хранятся **только в IndexedDB текущего браузера и сайта**, без сервера и синхронизации между устройствами. Очистка данных сайта или приватный режим могут удалить их. PNG нужен как резервная копия изображения, но не хранит редактируемые слои.
- Прежний черновик урока «Веточка с листьями» переносится из `localStorage` версии v1 при наличии старого ключа **на том же origin**. При смене домена браузер не предоставит доступ к исходному хранилищу; автоматический перенос через разные домены не поддерживается. Исходный ключ миграция не удаляет.

### Свой эскиз и референс (E1.6, Draft)

- В свободной студии доступны «Новый холст», «Поверх эскиза» и «Референс рядом». Выбранный PNG/JPEG/WebP открывает подтверждение размера нового документа: размер текущего холста либо загруженной картинки.
- Для обводки рисунок помещается на отдельный заблокированный слой под «Моим рисунком»; ластик работает только на активном paint-слое. Эскиз можно скрывать для самопроверки и менять прозрачность. Чтобы масштабировать, повернуть или сдвинуть изображение, сначала разблокируйте референс.
- В режиме «Референс рядом» картинка находится в самостоятельной панели, отдельно от масштабирования холста. На широком экране панель занимает около 35% рабочей области; её ширину можно менять мышью за разделитель или клавишами ←/→ при фокусе на разделителе. На планшете и телефоне панель располагается **над холстом**, сворачивается и не мешает вертикальной прокрутке.
- Для **просмотра референса** доступны кнопки ±, ползунок от 25 до 400%, масштабирование колесом мыши и жестом двумя пальцами, перетаскивание увеличенного изображения и сброс «Вписать». Эти действия не меняют референс как слой, масштаб рисования, историю или PNG; при повторном открытии просмотр начинается со 100%. Чтобы изменить само наложенное изображение, его по-прежнему нужно разблокировать.
- Файлы ограничены 10 МБ, стороной до 4096 px и площадью до 16 Мп; неподходящий либо битый файл не заменяет текущую работу.
- Blob сохраняется вместе с проектом локально в IndexedDB. Два E2E-сценария референсов вошли в успешно завершённый браузерный gate; Draft PR остаётся открытым до интеграции.

### Палитра, слои и PNG (E1.7, Draft)

- Свой цвет задаётся через HSV-поле или HEX, сохраняется в палитре проекта, а последние цвета доступны для повторного использования. **Пипетка** берёт итоговый цвет точки с учётом видимых слоёв и референса, но без маркеров выделения и масштаба редактора; после выбора снова активна кисть.
- Для выбранного слоя есть ползунок непрозрачности 0–100%. Название меняется через `⋯`, порядок — перетаскиванием либо клавишами ↑↓ на ручке слоя. Скрытый или заблокированный рисовальный слой не принимает новые штрихи.
- Кнопка **«Экспортировать PNG»** открывает окно, где можно включить или исключить наложенный эскиз-референс. PNG содержит изображение в исходных пикселях документа без управляющих элементов и масштабирования. По умолчанию эскиз исключён; для «Референса рядом» нечего включать в PNG.
- Все файлы обрабатываются локально в браузере. PNG не сохраняет структуру редактируемых слоёв — исходный проект продолжает храниться отдельно в IndexedDB. Автоматического облачного резервного копирования нет.

### Новые инструменты

- **Заливка ведром** — нажмите внутри замкнутого контура на выбранном слое. Ведро учитывает только границы этого paint-слоя; референсы и рисунки на других слоях не ограничивают заливку. На пустом слое заливается весь холст.
- **Фигуры** — выберите тип (прямоугольник, эллипс, треугольник, линия, стрелка) и стиль (контур, заливка либо оба). Протяните указатель по холсту для создания. Линия и стрелка всегда рисуются без сплошной заливки.
- **Переместить фигуру** — удерживайте уже нарисованную фигуру 0,5 секунды и, не отпуская, перетащите её. После выделения можно потянуть за угловые маркеры, чтобы изменить размер. Короткий мазок по фигуре действует выбранным инструментом (кисть, ластик, ведро, создание фигуры); перемещение сохраняется как одно действие Undo.
- **Прозрачность кисти** — ползунок 0–100%; ластик остаётся полностью стирающим. Настройка влияет на новые штрихи.

Все эти действия работают в активном видимом незаблокированном paint-слое. Пиксельная заливка воспроизводится в порядке команд; если изменить ранее нарисованную фигуру, заливка может пересчитаться под новым контуром.

Кнопки основных инструментов и изменения масштаба представлены пиктограммами, как в компактных панелях Excalidraw; при наведении показывают название, для клавиатуры и экранного диктора сохраняют доступные подписи. Текстовые настройки и подтверждение удаления остаются подписанными.

## Продуктовая идея

- Короткие занятия заканчиваются законченным рисунком и одновременно развивают конкретный навык.
- Обучение сочетает пошаговое повторение, осознанное построение формы и самостоятельный рисунок.
- Для взрослой аудитории предусмотрена программа из 12 уроков: кисти, палитры, слои, цвет, форма и композиция.
- Оформление вдохновлено профессиональными графическими редакторами: большой холст, компактные инструменты, минимум декора.
- Свободная студия позволит рисовать с чистого холста, загружать эскиз для обводки или держать референс рядом.
- Обратная связь по рисунку, испытания, достижения и награды включены в продуктовый план: сначала локальные проверяемые правила, без обещаний универсальной ИИ-оценки художественного качества.

## Запуск оболочки приложения

```bash
cd apps/web
npm ci
npm run dev
```

### Просмотр с планшета и других устройств локальной сети

Для рисования лучше запускать **собранную версию без Vite HMR**. Dev-клиент Vite при восстановлении WebSocket может вызвать `location.reload()` даже без действий пользователя. Автосохранение снижает риск потери, но ещё не записанные изменения при перезагрузке могут пропасть. Это возможная причина наблюдаемых перезагрузок, а не подтверждённый диагноз конкретного устройства.

1. Остановите предыдущий `npm run dev` через `Ctrl+C` (порт 5173 должен быть свободен).
2. Выполните из `apps/web`:

   ```bash
   npm run lan
   ```

3. На компьютере откройте `http://localhost:5173/`; на телефоне или планшете в том же Wi-Fi — `http://<IP-компьютера-в-локальной-сети>:5173/` (IP можно узнать командой `ipconfig` в Windows).

Этот режим не перезагружает страницу из-за обновлений исходного кода или восстановления HMR-соединения. После изменений кода сервер нужно перезапустить, чтобы пересобрать версию. Не открывайте редактор наружу в интернет; доступ предполагается только в доверенной локальной сети.

Проверки текущей оболочки:

```bash
npm run typecheck
npm run test:unit
npm run build
npm run test:e2e
```

Перед первым запуском E2E установите Chromium для Playwright: `npx playwright install chromium`. Для нестандартного пути к браузеру можно установить `ESKIZNO_CHROMIUM_PATH`. Тестирование стилуса и реального холста запланировано для последующих этапов.
